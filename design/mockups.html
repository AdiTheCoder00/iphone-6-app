Companion — 16 design directions

Every screen is the same markup at true 375×667, scaled down — so the proportions are honest, not flattering. Only a set of CSS custom properties differs between them, which means whichever you pick becomes a token block dropped into companion.html rather than a rewrite. Eye geometry, glow, ground, type and bubble shape are all part of each direction.

A · Warmer / softer

Less instrument, more lamp. For a desk you sit at in the evening.

B · Cool / technical

Stays cool and precise — the current language, executed four different ways.

C · More alive / expressive

More creature than appliance. Bigger eyes, stronger bloom, a mouth that reads.

D · Calmer / more minimal

Recedes until spoken to. Less colour, smaller features, quieter type.
